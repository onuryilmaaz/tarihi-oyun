# Terimler Sözlüğü

Proje boyunca bu terimler aynı anlamda kullanılır. Kodda İngilizce
karşılık (parantez içinde) kullanılabilir. [TASLAK] — terimler kullanıcı
onayıyla değişebilir.

## Belge ve süreç

| Terim | Anlam |
|---|---|
| [KARAR] | Kullanıcının açıkça seçtiği / doğruladığı gereksinim |
| [TASLAK] | Uygulanabilir ayrıntı; kodlamadan önce onay gerekir |
| [AÇIK] | Karara bağlanmamış konu; uygulama yapılmaz |
| Karar kaydı (DEC-XXXX) | `DECISIONS.md`'deki onaylı karar |
| Görev kartı (TASK-XXXX) | Bir işin kapsam ve kabul tanımı; onaysız kod yok |
| Aşama kapısı | Aşama sonunda kullanıcının açık onayıyla geçilen kontrol noktası |

## Zaman

| Terim | Anlam |
|---|---|
| Tur (turn) | Oyuncunun "Turu İlerle" ile başlattığı simülasyon dilimi |
| Tur süresi (turn length) | Bir turun oyun içi takvim karşılığı: 1 hafta / 1 ay / 3 ay / 1 yıl |
| İç adım (tick) | Simülasyonun tur süresinden bağımsız sabit hesap adımı |
| Kesinti (interrupt) | Uzun turun kritik olayda durup kararı oyuncuya bırakması |

## Harita ve toprak

| Terim | Anlam |
|---|---|
| Arazi birimi (territory) | En küçük fethedilebilir poligon alan; kabaca kaza/nahiye ölçeği |
| Yerleşim (settlement) | Şehir/kasaba; arazi biriminden ayrı nokta nesnesi |
| İdari birim (administrative unit) | Devlete özgü katman (ör. eyalet, sancak) |
| Yasal sahip (legal owner) | Bölgenin barışla tanınmış sahibi |
| Askerî kontrol (military controller) | Bölgeyi fiilen işgal eden devlet |
| İşgal (occupation) | Geçici askerî kontrol; yasal sahipliği değiştirmez |
| İlhak (annexation) | Barış veya kalıcı işlemle yasal sahipliğin değişmesi |

## Ekonomi

| Terim | Anlam |
|---|---|
| Hazine (treasury) | Devletin kullanılabilir parası |
| İsteğe bağlı harcama | Oyuncunun/otomasyonun başlattığı harcama; hazineyi aşamaz |
| Zorunlu gider | Maaş, bakım gibi tekrarlayan yükümlülük |
| Eksi bakiye | Zorunlu giderlerin hazineyi aşmasıyla oluşan negatif hazine; faiz yok |
| Borç | **Oyunda yoktur.** Kredi, faiz, tahvil, borç veren taraf bulunmaz |

## Askerî

| Terim | Anlam |
|---|---|
| Ordu (army) | Haritada hareket eden, komutanlı birlik grupları bütünü |
| Birlik grubu (unit group) | Ordu içindeki aynı türden birlikler |
| Moral (morale) | Ordunun savaşma iradesi |
| İkmal (supply) | Orduya erzak/malzeme akışı |
| Geri çekilme emri | Oyuncunun ordunun ne zaman çekileceğine dair verdiği karar |
| Kuşatma (siege) | Surlu yerleşimin zamana yayılan ele geçirilme süreci |
| Abluka (blockade) | Kara veya denizden ikmal/ticaretin kesilmesi |

## Devlet ve toplum

| Terim | Anlam |
|---|---|
| Senaryo | Tarihî başlangıç verisi paketi; ilk sürümde yalnızca 1453 |
| Alternatif tarih | Senaryo başladıktan sonra serbestçe gelişen olaylar |
| Veraset | Hükümdar değişimini belirleyen devlete özgü kurallar |
| Yerel yönetici | Rutin şehir/bölge yönetimini devralan karakter veya otomasyon |
| İsyan riski | Önceden görülebilen, nedenleri açıklanan huzursuzluk ölçüsü |
| Bilgi asimetrisi | Rakip verilerinin keşif/casusluk olmadan tam görünmemesi |
